 LIMIT , OFFSET AND FETCH.
 LIMIT can be used to limit the results coming from a query. 
 SELECT * FROM table_name LIMIT number of records;

OFFSET can be used to get records below a specfied limits
 SELECT * FROM table_name OFFSET number of records; - this gets all records underneath  a specified limits.
 SELECT * FROM table_name OFFSET number of records LIMIT number of data - Here the limits is added to specify the number of data that will be displayed or gotten.

FETCH does the same thing as LIMIT 
SELECT * FROM table_name OFFSET number to start FETCH FIRST number of records ROW ONLY;

IN - KEYWORD
IN - takes an arrays of values and return an arrays matching that values 
SELECT * FROM table_name WHERE Column_name IN ('values');

BETWEEN 
BETWEEN is used to find values within a range, including the two boundaries.
SELECT * FROM table_name WHERE Column_name BETWEEN 'Columns_value' AND 'Columns_value';


LIKE AND ILIKE
 LIKE AND ILIKE ARE USED FOR SEARCH TEXT PATTERN;

 LIKE IS CASE SENSITIVE in postgreSQL
 SELECT * 
 FROM product 
 WHERE name LIKE 'value%';

 "%" means any number of characters.

 "value%"  --starts with value.
 "%value"  --ends with value.
 "%value%  --contains value.
 "_at"     -- exactly one  character before "at"

 ILIKE works like LIKE , but is case-insensitive.

GROUP BY AND GROUP BY HAVING
GROUP BY is used to put rows with the same values into groups.

SELECT stock, COUNT(*)
FROM product
GROUP BY stock;

HAVING 
HAVING filters the groups created by GROUP BY.

SELECT stock, count(*) as total_product
FROM product 
GROUP BY stock
HAVING COUNT(*) > 1;

CALCULATING SUM , MIN, MAX AND AVERAGE.

MAX()  -  Highest value;
MIN()  -  Lowest value;
AVG()  -  Average value;
SUM()  -  Total

1. MAX() — highest price
SELECT MAX(price) as highest_value
FROM product;
Finds the most expensive product.

2. MIN() — lowest price
SELECT MIN(price) AS lowest_price
FROM product;
Finds the cheapest product.

3. AVG() — average price
SELECT AVG(price) AS average_price
FROM product;
Adds all the prices and divides by the number of products.

4. SUM() — total
SELECT SUM(price) AS total_price
FROM product;
This adds all product prices together.
